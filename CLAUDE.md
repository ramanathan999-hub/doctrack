# DocTrack

## What this product does

DocTrack tracks which commercial and export documents a shipment requires — by country,
customer, order type, Incoterm and payment term — then collects them, versions them,
routes them for signature, and distributes them to internal and external parties.

The document set is real-world export paperwork: invoices, certificates of origin and of
analysis, packing lists, ATR, T2L, bills of lading, sea waybills, COC and CTN for African
destinations, MSDS. Some are generated by the customer's ERP; many arrive from third
parties — freight forwarders, chambers of commerce, inspection bodies — by email or SFTP.
That second category is the hard part and the reason this product exists.

## Architecture context you cannot infer from the code

- The browser talks to Supabase directly. Row-level security is currently the **only**
  authorization layer. This produced IDOR findings on the supplier portal during
  self-directed penetration testing. It is a structural property of the design, not a bug
  that was fixed.
- WP-1 in `DOCTRACK_ROADMAP.md` replaces this with a server-side API layer. Until it
  lands, treat every new direct `supabase-js` call in client code as adding to that debt —
  raise it rather than adding one silently.
- Business logic currently lives partly in n8n Cloud workflows. It is migrating to the
  backend. Do not add new business rules to n8n; integration plumbing only.
- `order_activity` is an application log, not an audit trail. Do not treat it as evidence
  of anything.

## Standing rules

- Never run destructive operations against the production Supabase project
  (`syorwcsahfxbemvwdxrz`). Development work targets the dev project only.
- Security-critical work is test-first: write the failing test that demonstrates the hole,
  then close it.
- No secrets in the client bundle, in the repo, or in commit history.
- Real customer data never enters a non-production environment. Use the synthetic seed
  script.
- One roadmap work package per branch. Do not begin a package whose dependencies are
  unmet.
- Ask before adding a runtime dependency.
